The canonical grammar/source/implementation files above remain exact historical snapshots; their embedded version and maturity records describe that revision. Read react-setup.md and astro.md for current installation, Core dependencies and framework APIs. Original React 0.1.0 retains its tested theme 2.1.0 dependency; do not transfer that instruction to the current React 1 line. Shared grammar does not imply shared props or event/focus APIs.

The hosted read-only endpoint is https://krigsvolddesign.dev/mcp when available. The skill directory contains instructions and references only. The optional full agent archive contains a stdio server for offline/local transport; installing the skill does not install that server or create a remote connection. Check manifest family, sourceCommit and sourceDigest. Manual accessibility, localization/RTL and sustained use remain open.
