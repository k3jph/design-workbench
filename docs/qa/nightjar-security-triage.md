# Nightjar dependency security triage

Snapshot: 2026-10-29. Severity below is the advisory or npm-audit severity, not a finding that an exploit is reachable. Audit results change as advisory databases change. This is a dependency review, not a penetration test or a complete account of GitHub alerts.

## GitHub Dependabot alerts

GitHub reported 65 open alerts on `k3jph/design-workbench`'s default branch during a branch push: 4 critical, 25 high, 24 moderate and 12 low. Those are GitHub's alert counts, not unique affected packages, and cannot be mapped to the audits below without the individual alert records. The available GitHub connector rejects the Dependabot API endpoint as outside its supported endpoint families; the configured environment's enforced HTTP policy blocks direct `api.github.com`, and an unauthenticated request to the GitHub web security page returned 404. No credentials were inspected and no network-policy bypass was attempted. A repository security administrator should export or review all 65 records, including state, manifest path, affected version, advisory, dependency scope and remediation; prioritize reachable critical/high paths and reconcile them against the lockfiles listed here. Do not dismiss alerts on the basis of this report.

## Source-site repositories

Fresh npm audits of source-site main snapshots found 9 affected packages for `martlettheme/martlettheme` at `b588542` (one critical, four high, three moderate, one low) and 6 for `krigsvoldtheme/krigsvoldtheme` at `fa4a66c` (one critical, three high, one moderate, one low). Both lock Astro 5.18.2 and `sharp` 0.34.5. The critical Astro AVIF advisory above has no advertised patched 5.x or 6.x version in the npm advisory data; the latest examined 5.x is 5.18.2 and 6.x is 6.4.8. Astro 6.4.8 addresses the two high Astro advisories listed above but remains affected by the critical AVIF advisory. `sharp` has separately reported high advisories GHSA-f88m-g3jw-g9cj, GHSA-rgj7-g3m4-5g8c and GHSA-wq5f-xc86-pv6w. The Zod high finding is GHSA-mrhx-c7xc-m3w5; zod-to-ts is a dependent finding. Martlet additionally has high undici findings in Wrangler's Miniflare dependency chain, including GHSA-xjj6-f33q-929c, GHSA-4w7w-5xrc-9h26, GHSA-2m5v-pch6-74hx and GHSA-qrxm-fqhp-jwvm.

Both source sites configure Astro static output. A source search found no Astro image components, server adapter or View Transitions, so these audits do not demonstrate remote exploitation of the deployed static assets; untrusted inputs to builds or development tools remain a relevant boundary and a fuller reachability assessment is still needed. Separately review any Cloudflare Worker runtime and infrastructure dependencies. Experimental `nightjar/site-security` branches update the direct Astro dependency to 7.3.3 (the lowest version examined that clears the current Astro advisory set, including low GHSA-mpr7-6m5w-76rw) and Martlet Wrangler from 4.152.0 to 4.153.0, resolving the affected Miniflare/undici chain. The published family Astro adapters declare Astro 7 compatibility. This is a major Astro migration, not a patch-only update: both source-site Node floors change from 20.19 to 22.19 because the resolved unifont/undici 8.12.3 requires Node 22.19. Human review must assess the compatibility change, transitive lockfile updates and affected non-Linux optional packages before merging. No source-site release or deployment was performed.

The isolated `nightjar/site-security` branches are Martlet `6dfce87` and Krigsvold `1a0f3c1`. Each updated lock returned zero npm findings and passed a fresh install, 35 unit tests, a static build at Node 22.19.0, the Chromium site browser suite and a Wrangler worker **dry run**. Krigsvold's globally imported foundation stylesheet also contained an invalid `:global(...)` selector exposed by the newer minifier; its branch uses the equivalent global CSS selector and checks the resulting grid-card spacing in Chromium. The native Windows ia32 optional sharp artifact has its own restrictive Node engine range, and Windows and other platforms were not tested. No production deployment or manual security review is implied by these tests.

The checked-in workflows in each source-site repository have one CI workflow triggered on push and pull request; it builds, tests, and runs `wrangler deploy --dry-run`, and does not itself publish. External hosting or Cloudflare branch-preview triggers cannot be inferred from those files. The branches were pushed for review as draft [Martlet #32](https://github.com/martlettheme/martlettheme/pull/32) and [Krigsvold #31](https://github.com/krigsvoldtheme/krigsvoldtheme/pull/31); hosted verification runs `40975801734` and `40975805370` respectively passed. External hosting settings need confirmation. GitHub's push response separately reported 21 default-branch alerts for Martlet (one critical, ten high, seven moderate, three low) and 16 for Krigsvold (one critical, six high, six moderate, three low); these alert counts cannot be equated with the npm affected-package counts above without the individual records. Local patch exports remain available. No release or production deployment was performed.

The two native npm package branches and the two Astro package repositories returned zero npm audit findings at their inspected snapshots. This says nothing about older published versions or arbitrary consumers.

## Ruby lockfile coverage

RubyGems' advisory tool installation and the OSV endpoint were blocked by the configured proxy. As an alternative, the public `rubysec/ruby-advisory-db` and `rubysec/bundler-audit` repositories were cloned through the allowed GitHub host. Bundler Audit's `Scanner` API was run locally against both Nightjar Jekyll `Gemfile.lock` files with no ignored advisories. The scan returned no matching advisories or insecure sources. Database commit: `920f5cd5e02cbe598f60afb02f533d608133b795` (2026-10-29); scanner source commit: `831cdc92a029af6df828654133e407c81f90330b`. This covers known records in that database for the locked gems and sources, not vulnerabilities in Ruby itself, unrecorded advisories, or runtime exploitation.

Example commands using pre-cloned sources and Ruby/Bundler already provisioned for Nightjar:

```sh
export BUNDLER_AUDIT_DB=/path/to/ruby-advisory-db
ruby -I /path/to/bundler-audit/lib -r bundler/audit/scanner -e 'ARGV.each { |root| puts "#{root}: #{Bundler::Audit::Scanner.new(root).scan.map(&:to_h)}" }' examples/jekyll/martlet examples/jekyll/krigsvold
npm audit --audit-level=low
npm audit --prefix examples/astro-slice --audit-level=low
```
