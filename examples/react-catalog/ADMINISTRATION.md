# React administration component

`src/dashboard/Administration.tsx` is an isolated, paired React component using the Northlight synthetic people fixture and the framework-neutral collection, validation and bulk-action functions. It owns its controlled filter drafts, applied scope, stable-ID selection, preview states, editor, dialog and page-memory records. No save, bulk action or preview sends data to a server; reload restores the fixture. User-entered values are rendered as text. Form errors retain the draft and focus an error summary; dismissing the confirmation returns focus to its triggering action. When paging reaches a boundary, focus moves to the available control.

The server-rendered component shows all 24 directory records and disables interactive controls until hydration. The test harness uses the existing family-specific React packages, server rendering and hydration at root and subpaths. From the workbench root run `CHROMIUM_PATH=/usr/bin/chromium node examples/react-catalog/test-administration.mjs`. Checks cover selection across pages, confirm and Escape cancellation/focus, scoped status changes, search, validation/focus and draft retention, safe text, simulated loading/error recovery, malformed page numbers, narrow reflow, light/dark automated axe and the no-JavaScript directory fallback. A focused TypeScript check with `allowJs` verifies this component and its harness; the shared model remains JavaScript.

This is an isolated component and test harness, not yet wired into the prerendered React catalog, dashboard navigation or peer comparison. Visual parity, manual assistive-technology review, other browser engines, cross-framework end-to-end behavior and production service integration remain open. The underlying React component APIs are experimental.
